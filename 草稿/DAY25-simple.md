**撰寫範圍（100 字內）：** 將 Day 09 的提示詞整理成團隊模板，加入範例輸入、期待輸出、誤報處理與禁止提交的敏感資料。

### 作者驗證案例

- [ ] 使用至少兩個不同 Java diff 測試模板。
- [ ] 測試案例同時包含應抓到與不應誤報的內容。

- [ ] 失效案例與已知限制有記錄。
