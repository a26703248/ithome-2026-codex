# DAY12 AGENTS.md 範本

這個目錄只保存文章展示用的 `AGENTS.md` 範本，並不是一個可直接執行的 Maven 專案。

要在 Day 10 案例比較加入規則前後的差異，第一輪先不要複製範本，直接從 `程式碼/DAY10/` 啟動 Codex 並記錄結果。接著把 `AGENTS.md` 複製到 `程式碼/DAY10/`，讓它與 `pom.xml` 位於同一層；重新啟動 Codex，再以完全相同的任務執行第二輪。Codex 只會沿著專案根目錄到啟動時目前工作目錄的路徑尋找指令檔；放在相鄰的 `程式碼/DAY12/` 不會套用到 DAY10。

兩輪都要比較讀檔範圍、錯誤假設、測試命令與完成回報。這份範本指定的驗證命令是：

```powershell
mvn clean test
```
