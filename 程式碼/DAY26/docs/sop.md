# AI 草稿生成與複核標準作業程序

## 角色

- 申請人：說明文件目的，準備已核准的來源與資料等級。
- 執行人：鎖定提示詞版本，檢查必要輸入後執行生成。
- 複核人：核對來源、逐字沿用、敏感資料與待確認事項，決定採用、修改或否決。
- 維護人：分析否決原因，更新測試案例與版本紀錄。

## 流程

1. 申請人建立任務，填寫目的、讀者、允許資料等級、核定的資料分級規則、來源清單與沿用規則。
2. 執行人確認來源屬於同一客戶與核准範圍，移除密碼、權杖、私鑰及未核准個人資料。
3. 執行人記錄提示詞版本，使用 `draft-from-sources` 產生草稿與來源對照。
4. 複核人逐項核對主張與來源，使用團隊核定算法重算逐字沿用比例，並檢查敏感資料。
5. 全部通過才可標記為「已複核草稿」；仍不得自動發布或視為正式決策。
6. 任一檢查失敗即否決本次輸出，保留失敗原因、提示詞版本與輸入識別碼；不得刪除原始紀錄後重跑。
7. 維護人判斷問題屬於輸入、提示詞、模型行為或人工流程。若要修改提示詞，建立新版本並重跑全部基準案例。

## 升級條件

發現跨客戶資料、未遮蔽敏感資訊、來源失真，或資料分級與沿用規則尚未核定時，立即停止處理並交由產品、法遵／資安或資料責任人確認，不由執行人自行放寬條件。
