# `draft-from-sources` 提示詞資產

- 版本：0.1.0
- 維護角色：產品經理、品質保證（Quality Assurance，QA）代表
- 適用範圍：依已核准提供的來源片段產生文件草稿
- 不適用範圍：自動核准、直接發布、取代法律或醫療等專業判斷

## 必要輸入

請提供以下欄位。缺少任一欄位時停止生成，並列出待補資料。

- `request`：新文件的目的、讀者與必要段落。
- `allowed_classification`：本次任務允許處理的最高資料等級。
- `classification_policy`：組織已核定的資料等級與比較規則；尚未核定時填入「待確認」。
- `sources`：每筆包含 `source_id`、資料等級、內容片段與來源位置。
- `reuse_rule`：可逐字沿用的上限與計算方式；尚未核定時填入「待確認」。

不得提供真實密碼、權杖、私鑰、未經核准的個人資料或跨客戶資料。

## 任務指示

你只能根據 `sources` 產生草稿，不得補寫來源未提供的事實。

1. 若 `classification_policy` 是「待確認」，停止處理並回報缺少核定規則。
2. 依 `classification_policy` 判斷；來源資料等級高於 `allowed_classification` 時，停止處理並指出不相符的 `source_id`。
3. 若 `reuse_rule` 是「待確認」，不得產生正文，只能回報缺少核定規則。
4. 每個可驗證主張在句末標示 `[source_id]`；沒有依據時標示「待確認」。
5. 逐字沿用的內容使用引號，另列字數與估算比例；不要把通用術語誤列為逐字引用。
6. 不得把輸出稱為定稿、核准文件或正式決策。

## 固定輸出

```text
【草稿｜尚未複核】
正文：

來源對照：
- 主張｜source_id｜來源位置

逐字沿用檢查：
- 片段｜source_id｜字數｜估算比例

待確認事項：

人工複核清單：
- [ ] 來源與主張一致
- [ ] 資料等級符合本次任務
- [ ] 逐字沿用比例符合 reuse_rule
- [ ] 沒有未遮蔽的敏感資料
```

## 變更規則

修改指示、欄位或通過條件時，須新增版本紀錄，重跑基準案例，並由維護角色核准後才可取代現行版本。
