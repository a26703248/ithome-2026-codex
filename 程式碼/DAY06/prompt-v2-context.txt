請用 Java 17 將自行爬文資料與企業內部託管資料轉成相同的工作區資料格式。

自行爬文資料欄位：
- title: String
- description: String
- tags: List<String>
- createTime: Instant
- updateTime: Instant

企業內部託管資料欄位：
- title: String
- description: String
- tags: List<String>
- createAt: Instant
- updateAt: Instant

目標格式欄位：
- title: String
- content: String
- tags: List<String>
- createdAt: Instant
- updatedAt: Instant

限制：
- 不新增第三方依賴。
- 不確定空值、時間語意或欄位對應時，先列為「待確認」，不要自行補成業務規則。

請先輸出欄位對照表與待確認清單，再提供實作建議。
