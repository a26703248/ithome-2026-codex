## 已知限制

- 逐字沿用比例仍需由程式或人工以相同算法複算，不能只採信模型自報數字。
- 通用術語與具原創性的連續文字之間沒有單一通用門檻，正式規則須由內容與法遵角色核定。
- P-04 的分級順序只供合成案例走查；正式環境必須改用組織已核定的 `classification_policy`，沒有規則時停止處理。
- 更換模型、提示詞版本或來源格式後，以上案例都要重跑；本次通過不能外推到所有產業與文件。
