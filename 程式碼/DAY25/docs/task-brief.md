# Day 24 Codex 任務說明

這是一個獲准公開的 Java 17／Maven 最小案例。請只修改 `程式碼/DAY24/`，不要改動其他 Day 的文章、程式與測試。

## 已確認條件

- 複核決策包含 `ACCEPTED`、`MODIFIED`、`REJECTED`。
- 修改必須新增版本，不得覆蓋原始草稿。
- 本次最小驗收規定：每種決策的複核原因不得空白，且要留下複核者。
- 不得加入自動核准或自動發布。

## 實作範圍

- 新增一個不依賴框架的 `ReviewWorkflow`。
- 以 JUnit 5 驗證採用、修改、所有決策的複核原因與原稿保留。
- 執行 `mvn clean test`，回報命令摘要與實際測試數。

## 非目標

- 不實作使用者介面、資料庫、登入授權、稽核儲存、版本衝突處理或部署設定。
- 不推論正式系統已具備最小案例以外的能力。
