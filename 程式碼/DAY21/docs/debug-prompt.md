# Day 21 Codex 除錯任務

```text
先不要修改檔案。重現「後面的客戶較晚才開始產生報表」，並建立證據鏈。

已知行為：批次依序讀資料、產生 PDF、呼叫 MailGateway。
初始假設：資料量、PDF 產生器或郵件回應時間可能造成等待。

請依序完成：
1. 以單調時間分別記錄 prepare、read、pdf、mail 的開始與耗時。
2. 診斷紀錄只保留測試客戶代號與毫秒，不得輸出附件內容、收件人或憑證。
3. 每次只替換一個測試替身，比較第二份報表的開始時間。
4. 找到根因後提出最小修正，禁止加入無限制平行處理或改動對外資料格式。
5. 執行局部與完整測試，回報命令、數字與尚未驗證的正式環境風險。
```
