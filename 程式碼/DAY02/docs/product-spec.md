# 產品規格書（節錄）— 商品查詢功能

> 本文件為 Day02 案例用的簡化規格書，供 Codex 修正缺陷時作為對照依據。

## 1. 功能範圍

提供內部後台「商品查詢」API：使用者可依關鍵字、分類篩選商品，並指定排序方式與分頁。

- 對應程式：`com.ithome.day02.search.ProductSearchService#search`

## 2. 關鍵字查詢規則

- 關鍵字比對**須忽略大小寫**，例如使用者輸入「iphone」，必須同時比對到「iPhone 15 Pro」與「iphone 13」。
- 關鍵字為 `null` 或空字串時，視為不篩選。
- 關鍵字比對範圍為商品名稱（`Product#name`）。

## 3. 排序與分頁規則

- 排序**必須套用在整體結果集**上，再依 `page`、`size` 切出該頁資料。
- 不可先分頁、後排序，否則會造成同一組排序條件下，跨頁資料的順序不連續（例如第 1 頁最後一筆的價格，可能小於第 2 頁第一筆）。
- 分頁頁碼 `page` 從 0 開始。

## 4. 分類篩選規則

- 分類為 `null` 或空字串時，視為不篩選。
- 分類比對為完全相符。

## 5. 已知例外情境（待確認，非本次修正範圍）

- 關鍵字含前後空白時的處理方式。
- 商品名稱含特殊字元（例如全形符號）時的比對行為。
- 大量資料（千筆以上）分頁查詢的效能。
