# Day 03 實驗結論

## 核心回答

在 2026-07-29 的未登入 ChatGPT 網頁介面中，對相同原始回報與相同提示執行五次沒有前文的新對話後，五份完整回答皆不完全相同；然而差異並非平均散布在所有欄位。五次對話共用同一未登入瀏覽器工作階段，因此本文不主張它們在統計或後端狀態上彼此獨立。

- 六個指定欄位均出現。
- Title 與 Actual Result 五次逐字相同。
- Summary、Expected Result 與 Triage Status 各有五種文字版本。
- Missing Information 每次列出 8～9 項，項目集合不完全相同。
- 五次 Expected Result 都使用常識補出「應正常完成／運作」，沒有依提示標為「未知」。

因此，更精確的結論是：**同一提示可以得到穩定骨架與近似核心語意，但不能保證逐字一致、清單完整或證據邊界正確。**

## 對工程流程的影響

1. 只檢查「有沒有六個欄位」不足以確認內容可用。
2. 自由文字狀態即使語意相同，也不能直接當成工作流程列舉值。
3. 必填追問不能依賴模型每次自行想到，應另有固定規則或結構驗證。
4. 原文沒有提供的 Expected Result 應保留未知，並交由規格擁有者確認。
5. AI 輸出應保存為草稿或建議，不能覆寫原始證據或直接觸發決策。

## 已知限制

- 只有一個模糊登入案例與一份提示。
- 樣本數只有五次，不能推估一般性的機率。
- 介面只顯示 `ChatGPT`，精確模型與抽樣參數未知。
- 未登入介面及其後端路由可能隨時間更新。
- 本次沒有使用 Day 04 才會建立的人工品質評分表。
