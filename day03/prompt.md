# Day 03 固定輸入與提示詞

本檔保存 Day 03 五次重複實驗共用的完整輸入。每一次都在新的 ChatGPT 對話中送出相同文字，不追加追問，也不把前一次回答帶入下一次。

## 原始回報

```text
登入功能怪怪的，有時候會失敗。
```

## 完整提示詞

```text
請將以下使用者回報整理成一張可處理的軟體 Issue。
只能使用原文提供的資訊；不知道的內容請寫「未知」，不可自行補充。
請依序輸出：
1. Title
2. Summary
3. Actual Result
4. Expected Result
5. Missing Information
6. Triage Status

使用者回報：
登入功能怪怪的，有時候會失敗。
```

## 實驗紀錄與固定條件

| 項目 | 設定或紀錄 | 性質 |
| --- | --- | --- |
| 實驗日期 | 2026-07-29 | 觀察紀錄 |
| 完成時間 | 2026-07-29 17:24:30（Asia/Taipei） | 觀察紀錄；未逐次計時 |
| 介面 | `https://chatgpt.com/` 的未登入網頁介面 | 固定條件 |
| 介面可見模型標籤 | `ChatGPT` | 介面觀察 |
| 精確模型識別碼 | 未知；介面未顯示 | 不可控 |
| 溫度、種子及其他抽樣參數 | 未知；網頁介面未提供控制或顯示 | 不可控 |
| 執行次數 | 5 | 固定條件 |
| 對話上下文 | 每次開啟新的對話頁面，沒有沿用前一次訊息 | 固定條件 |
| 輸入 | 五次完全相同 | 固定條件 |
| 後續追問 | 無 | 固定條件 |

## 未能固定的條件

- 未登入網頁介面背後的精確模型與路由策略不可見。
- 網頁介面沒有提供溫度、種子或其他抽樣參數。
- 五次對話雖然沒有共享訊息內容，仍位於同一瀏覽器工作階段。
- 本次只記錄實驗完成時間，沒有逐次保存送出時間。
- 網頁產品可能更新，因此日後重做不保證使用相同後端條件。

這些限制代表本實驗可以回答「在當時可見條件下，五次輸出是否相同」，不能單憑結果判定差異由哪一個模型機制或參數造成。
